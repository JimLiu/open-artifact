A setting that takes effect at once: on is `forest`, never `accent`, because a setting is a state and not the action of the view.

- The label names the thing that is on ("Pause deliveries"), not the action ("Turn on pause").
- The whole row is the target, 44px tall or more. The hint under the label says what on means.
- For a choice that needs a Save button, use a checkbox in a form instead.
- You provide `label`, `checked` and `onChange`.
