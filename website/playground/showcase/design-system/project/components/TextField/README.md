One line of text with a label above it and a hint below. The label is always visible: a placeholder is an example, never the label.

- The hint says what happens with the answer ("One email per delivery"). In the error state it becomes the message: what is wrong and how to fix it, with an icon, in `text-danger`.
- The border is `line-strong` so the field reads as a control on every surface; focus adds the `accent-focus` ring.
- You provide `label`, the value and, if it can fail, `error`. Width comes from the container: fields fill their column.
