Each demo is the real product: the real Shell and the real editor, running entirely in your browser over an in-memory artifact. The agent is simulated, so you can see the comment loop without installing anything. 每个演示都是真正的产品：真正的 Shell 和真正的编辑器，完全在你的浏览器里运行，背后是一个内存里的产物。Agent 是模拟的，不用安装任何东西，就能看到评论如何回到 Agent、Agent 又如何修改产物。

  1. Edit directly: retype text, move things, change a cell.直接编辑：改文字、挪元素、改单元格。
  2. Comment on any spot and tick “Send to Agent”.留评论，并勾选“发给 Agent”。
  3. Watch the agent reply in the thread and change the artifact live.看 Agent 在评论里回复，并实时修改产物。

Nothing is saved: reload a demo to start over. Works best in a desktop browser. To use it with your own agent, install Open Artifact. 不会保存任何内容：刷新页面即可重来。在桌面浏览器里体验最好。想配合你自己的 Agent 使用，请安装 Open Artifact。
